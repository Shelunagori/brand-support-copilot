# Urbane Threads Returns Policy

Policy-ID: UT-RET-001
Status: ACTIVE
Effective: 2026-04-01
Owner: Customer Experience, Urbane Threads (urbanethreads.in)
Replaces: UT-RET-000 (Legacy Returns Policy 2024, now SUPERSEDED)

## 1. Purpose and scope

This document is the single source of truth for returns on orders placed directly on urbanethreads.in (website and app). It applies to all apparel and accessories sold by Urbane Threads to customers in India. Orders placed on Amazon or Flipkart are NOT covered by this policy; those follow the marketplace's own return process (see UT-MKT-008).

If any other document, archived FAQ, blog post or promotional banner gives a different return window, this policy wins. The old 30-day return window from 2024 is no longer valid.

## 2. The core rule

- **Return window: 7 days from the date of delivery.**
- The item must be **unworn, unwashed, and with all original tags attached**, in its original packaging where possible.
- The 7 days are counted in calendar days starting the day after the delivery date shown in the tracking record.
- A return request must be raised (not merely shipped) within the 7-day window.

Exchanges have a separate, longer window of 15 days from delivery; see UT-EXC-002.

## 3. Items that cannot be returned

Innerwear, socks, and any product marked **"Final Sale"** on the product page or invoice cannot be returned or exchanged under any circumstances, except where the item arrived damaged or wrong and was reported correctly under UT-DMG-009. See UT-NRT-003 for the full list.

## 4. How a customer raises a return

1. Log in at urbanethreads.in, go to **My Orders**, select the item and tap **Return**.
2. Choose a reason and upload a photo showing tags attached (optional but recommended).
3. A reverse pickup is scheduled within 1-2 business days in serviceable pincodes. In non-serviceable pincodes, the customer self-ships to our Bengaluru warehouse and the courier cost is reimbursed as store credit up to ₹100.
4. Once the item passes quality check (QC), the refund is triggered as per UT-REF-004.

Customers can also email support@urbanethreads.in with the order ID if they cannot use the self-serve flow.

## 5. Quality check outcomes

- **QC pass:** refund initiated within 48 hours of the item reaching the warehouse.
- **QC fail (worn, washed, perfume/deodorant marks, tags removed):** the item is shipped back to the customer and no refund is issued.

## 6. Worked examples

- **Example A:** Kurta delivered on 10 May. Customer requests a return on 16 May. That is day 6, so the return is accepted.
- **Example B:** Denim jacket worth ₹2,499 delivered on 1 June. Customer asks on 12 June. Day 11 is outside the 7-day return window. The return is declined, but an exchange is still possible until day 15 (UT-EXC-002).
- **Example C:** Customer quotes "your website said 30 days returns". The 30-day window belonged to the 2024 policy (UT-RET-000), which was superseded on 2026-04-01. Agents must politely explain the current 7-day window.
- **Example D:** Socks pack bought on the website, unopened, day 2. Not returnable (UT-NRT-003).

## 7. Sample customer phrasings (including Hinglish)

- "Mujhe ye shirt return karna hai, size chhota hai." -> Check delivery date; if within 7 days and tags intact, guide to the return flow, and mention exchange as an option.
- "Return ka time kitna hai?" -> 7 days from delivery for returns, 15 days for exchange.
- "I bought this on Amazon, can you take it back?" -> Redirect to Amazon (UT-MKT-008).

## 8. Frequently asked questions

**Q: Is the return window 7 days from order or from delivery?**
A: From delivery.

**Q: Can I return an item I tried on once at home?**
A: Yes, trying on is fine as long as it is unworn outside, unwashed and all tags are attached.

**Q: Is there a return shipping fee?**
A: No. Reverse pickup is free for website orders. Original shipping charges (₹79 on orders below ₹999) and COD fees (₹49) are not refunded on a voluntary return.

**Q: Can I return part of an order?**
A: Yes, individual items can be returned. If the remaining order value falls below ₹999, the original free-shipping benefit is not clawed back.

**Q: The festive sale said 20-day returns. Does it still apply?**
A: No. That was a Diwali 2025 promotion that has expired. The current window is 7 days.

## 9. Agent guidance

Always cite **UT-RET-001** when answering return questions. Never promise a return outside 7 days; offer an exchange (UT-EXC-002) if the customer is within 15 days. Escalate per UT-ESC-012 for legal threats, chargebacks or orders above ₹25,000.
